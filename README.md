## Problemas encontrados
- API estava incorreta (post ao invés de posts)
- Dados não eram exibidos corretamente
- Falta de tratamento de erro

## Correções realizadas
- Ajuste da URL da API
- Uso do método join() para renderização correta
- Implementação de tratamento de erro
- Adição de mensagem de carregamento

## Melhorias
- Interface estilizada com CSS
- Organização dos dados em formato de cards

## Resultado final
A aplicação agora busca dados corretamente da API e exibe na tela de forma organizada e funcional.
